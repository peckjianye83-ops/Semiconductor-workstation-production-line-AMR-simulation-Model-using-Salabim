This is code of a Salabim simulation model of a semiconductor workstation production line which is configured with a different number of AMRs and different number of zones. 
The simulation model limitation has been tested by using an exceeding number of AMRs deployed, the outcome analysis can help in future planning of resource allocation.

The program is created using python 3.14, in visual code studio.

1-10 AMRs & Zones(23July2026).py is the simulation model version for setup from 1-10 AMRs and 1-10 zones which work normally in the production line.

Flexible unlimited AMR number(19August2026).py is the version which setup do not have limitation for number of AMR that deployed in the system, 
this is use to test the maximum capacity threshold of the system can handle.
